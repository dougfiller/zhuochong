# 助手原生聊天画布设计

**日期：** 2026-07-29  
**状态：** 已经用户确认  
**方向：** C — ChatGPT 的操作熟悉度、Claude 的阅读舒适度，加上 Work Review 自己的工作脉络表达

## 1. 目标

把助手页面从传统业务工作台调整为轻量聊天画布：第一眼聚焦提问，回答以连续文稿呈现，模型、数据范围、工具过程和引用只在需要时出现。

设计不得复制任何单一 AI 产品的品牌视觉；延续 Work Review 已有的中性表面、低对比边界、清晰留白和深色模式规范。

## 2. 页面结构

页面保留全局侧栏，不新增助手专属常驻侧栏。

助手页由三层组成：

1. 紧凑会话栏：左侧显示统一的“对话气泡 + 闪光”身份标识、当前会话标题和保存状态；右侧保留历史会话、新对话。
2. 居中聊天画布：空状态略高于视觉中心；消息态使用 720–800px 阅读轴。
3. 浮动输入区：输入、工作脉络、真实模型名称、发送/停止按钮位于同一圆角容器。

删除传统大页头、灯泡徽章、常驻上下文条和重复模型展示。

## 3. 空状态

欢迎标题保持居中，说明文案改为简短版本：

> 结合工作记录，为你提炼重点。

不再使用“我会结合你的时间线、日报和网站记录，帮你找到真正值得关注的内容”这类长句。

快捷问题保留最多四项，但改为轻量入口：

- 第一项可以横跨整行，作为首要建议。
- 其余使用两列紧凑布局。
- 删除数字编号、箭头装饰和上浮动画。
- 移动端改为单列。

## 4. 消息态

用户消息继续右对齐，使用中性浅色气泡，不使用高饱和蓝色边框。

助手回答直接排版在画布上：

- 删除整张回答卡片的背景、边框、圆角和阴影。
- 保留 Markdown 标题、段落、列表、代码和表格的必要排版。
- 使用留白而不是卡片边界区分轮次。
- 助手回答顶部使用与页头一致的小型身份标识。

工具过程保留折叠能力，但默认呈现为一条紧凑状态行；只有运行中、失败和待确认状态使用强调色。

风险操作确认仍使用独立内联提示块，不能因极简而隐藏。

## 5. Work Review 原生创新

### 5.1 今日工作脉络

在输入框左下方增加轻量上下文入口，替代常驻上下文条。

默认只显示“今日工作脉络”；展开后显示：

- 当前日期；
- 可参考的数据来源（时间线、日报、网站记录等）。

此入口使用原生 `details/summary`，支持键盘操作并保持轻量，不增加新依赖；真实模型名称只在相邻模型选择器中展示一次。

### 5.2 回答依据线

当回答包含引用时，在正文底部显示低存在感的依据线：

- 汇总引用数量和来源类型；
- 默认收起；
- 展开后使用单列紧凑来源列表；
- 不再使用多列引用卡片。

### 5.3 统一助手身份标识

页头与回答内部使用相同的“对话气泡 + 小闪光”图形，和侧栏助手的对话语义一致；不再使用灯泡。

## 6. 输入框

输入框继续支持自动增高、中文输入法、Enter 发送、Shift+Enter 换行和停止生成。

视觉调整：

- 最大宽度约 800px；
- 圆角 20–22px；
- 工具行无贯穿式分隔线；
- 模型选择保持原有功能，但视觉改为轻量胶囊；
- 只显示真实当前模型名称，不重复显示“基础模型”；
- 发送/停止按钮使用圆形；
- 错误提示和 AI 免责声明放在输入框附近的弱层级区域。

## 7. 历史会话

继续使用右侧抽屉，不新增第二侧栏。

页头不再展示醒目的会话数量角标；数量移动到历史抽屉标题或说明中。历史、新对话按钮在窄屏只显示图标，并保留 `aria-label` 与 `title`。

## 8. 响应式与深色模式

- 720px 以下缩小页面安全边距，用户气泡最大宽度提升到 90%。
- 520px 以下快捷问题改单列，页头只保留图标操作。
- 深色模式边界使用与概览一致的低对比变量，禁止亮白外框。
- 助手正文在深色模式中不使用额外边框或阴影。

## 9. 不在本次范围

- 不修改模型调用、会话持久化、流式响应和确认逻辑。
- 不新增依赖。
- 不增加附件上传、联网开关或新的后端接口。
- 不重构全局侧栏。
- 不修改 `CHANGELOG.md`。
