# 助手统一页头与随机问题设计

## 目标

让助手页面与概览、时间线、设置、关于页面保持一致，同时减少欢迎态空白，并让快捷问题真正具有随机性和分析价值。

## 页面结构

- 左上角复用全局 `page-header`、`page-title-group`、`page-title-badge`、`page-title-copy` 结构。
- 页面标题显示“助手”，副标题显示当前会话标题。
- 历史会话和新对话保留在页头右侧。
- 欢迎主标题改为“问问你的工作记录”，说明改为“提炼重点，发现线索。”。
- 欢迎区缩短纵向留白，主标题在常规桌面宽度保持单行。
- 快捷问题固定显示四条，采用两列两行布局。

## 随机问题

- 四语言各提供不少于 16 条候选问题。
- 候选问题覆盖时间节奏、工作内容、应用与项目、复盘行动。
- 页面进入、新建对话、切换模型时重新抽取四条。
- 单次结果不重复，并尽量避免连续两轮得到完全相同的组合。
- AI 模型生成的问题与本地问题池合并后再随机抽取；生成失败时仍使用本地随机结果。

## 参考记录

- 将“今日工作脉络”改为“参考记录”。
- 明确说明助手会根据问题自动选择时间范围。
- 展示可参考的数据来源：活动、时段摘要、日报与记忆。
- 该入口只解释回答依据，不暗示查询范围固定为今天。

## 视觉约束

- 保持干净、低对比、不过度卡片化。
- 快捷问题字体提高可读性，四张卡片高度一致。
- 深色模式继续使用共享低对比边界变量。
- 720px 与 520px 宽度下仍保持两列两行，避免横向溢出。
