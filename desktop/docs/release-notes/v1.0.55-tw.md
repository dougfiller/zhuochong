# Work Review v1.0.55

**發布日期**：2026-07-09

## 修復

- **WebView 原生右鍵選單**（#126）：應用殼層現在全域攔截預設右鍵選單，並加入監聽與清理邏輯的回歸測試。
- **概覽指定日期選擇器**（#119 / #127）：日期選擇器浮層改為掛載到 `body` 並使用 `fixed` 定位，避免被概覽容器裁切；日期範圍前後切換也改為一致口徑。
- **助手時間上下文**（#122）：助手提示詞會注入目前日期與時間，避免回答中出現過期或錯誤時間。
- **桌寵多螢幕位置**（#120）：桌寵位置會依螢幕資訊持久化，降低重啟或跨螢幕拖曳後的漂移。
- **設定頁更新開關**：自動檢查更新開關會立即持久化，避免下次啟動仍使用舊設定。
- **啟動與 Linux 發布鏈路**：修復開機自啟、Linux release workflow 與打包校驗問題。
- **建構 CSS 警告**：避免 Tailwind 將 Markdown 表格分隔線正則誤判為任意屬性 class，移除生產建構的 CSS minify syntax warning；新增建構警告守護測試。

## 優化

- **日報頁面**：更新日報視覺結構並收緊 Markdown 表格排版，表格右側不再留下大塊空白。
- **工作助手**：優化模型選擇器尺寸、Markdown 渲染與串流輸出節流，長回答閱讀更順。
- **設定頁本地 API**：端點未啟用或明確為本機地址時跳過無意義自動測試，減少誤報。

## macOS 安裝說明

首次啟動可能看到「已損壞」提示，執行：

```bash
sudo xattr -rd com.apple.quarantine '/Applications/Work Review.app'
```
