# Work Review v1.1.0

**發布日期**：2026-07-31

跨版本發布（MINOR）：新增功能、無破壞性變更。

## 新增

- **內建分類知識庫**：約 140 個網站域名 + 70 個應用的確定性分類，瀏覽器活動依站點內容細分（B 站→娛樂、GitHub→開發），不再一律歸「瀏覽器」。
- **AI 實體自動學習**：背景自動歸類未識別的應用/域名並回溯修正近 14 天歷史，分類隨使用自動變準。
- **語意記憶系統**：新增「記憶」能力，可語意搜尋看過的螢幕內容，支援本地 Ollama 或 OpenAI 相容嵌入源；嵌入不可用時降級為關鍵字檢索。
- **6 個新 AI 服務商**：OpenRouter、Groq、xAI Grok、Mistral、LM Studio、自訂 OpenAI 相容端點。
- **模型/搜尋測試按鈕**：語意記憶區「測試模型」、助手聯網區「測試搜尋」，先測通再啟用。
- **Agent 能力擴展**：循環放寬到 120s、新增停止按鈕、注入即時前景上下文；工具從 6 個擴展到 12 個，並新增 6 個需前端確認的寫操作工具（建立待辦、改分類、暫停/恢復錄製等）。
- **對話持久化**：助手歷史存入 SQLite（取代 localStorage），支援切換/刪除/新對話，舊歷史自動匯入。
- **時間線雙抽屜**：小時摘要和活動詳情改為右側抽屜，集中展示截圖、活動資訊與分類編輯。
- **網站全量瀏覽與語意編輯**：概覽支援展開全部網站及單域名詳情，可直接修改網站語意分類並回填歷史。
- **注入防護**：外部內容用邊界包裹防提示注入，Gemini Key 改走請求標頭，系統指令不再拼進 user content。
- **隱藏桌寵本體**（#137）：新增「隱藏桌寵形象」開關，開啟後僅保留通知與提醒氣泡、隱藏桌寵本體並收縮視窗；適合只想用通知、不需要桌寵形象的場景。

## 修復

- **統計邊界與時區**：重疊工作時段按聯集計時、加班排除娛樂活動；跨午夜工作階段按天裁剪；非整小時時區（UTC+5:30 等）的小時圖不再歸錯。
- **統計口徑統一**：分類構成條、娛樂佔比、洞察句與總投入同源，頁面頂層數字不再對不上。
- **隱私過濾加固**：視窗標題入庫前過濾郵箱/手機/卡號；修復銀行卡正則從未生效、卡號原樣入庫的問題。
- **時長計算修正**：切到忽略應用不再吞掉上一應用時長，切回舊應用不再合併為偽連續區間。
- **儲存清理定期執行**：保留天數/容量清理改為每 6 小時背景跑一次，長駐應用也生效。
- **Telegram Bot 斷網重連**：按指數退避無限重試，不再連續 3 次失敗就永久停機。
- **MCP 日報委託逾時**：從 2 秒放寬到 120 秒，未快取 AI 日報不再委託失敗。
- **小時摘要效能**：僅重算缺失或過期的摘要，不再每次查看全量重算並寫庫。
- **截圖補傳兜底**：背景每 10 分鐘掃描近 72 小時漏傳截圖自動補傳。
- **「測試連接」改測表單當前值**：所見即所測，填完直接點測試不再誤報「未設定」。覆蓋範圍延伸到「測試搜尋」「測試模型」——選了免費搜尋方案但未點儲存就測試，不再誤報要求 Tavily API Key。
- **免費搜尋（Bing）容錯**：`www.bing.com` 在部分網路（尤其國內）會間歇性連線逾時，免費搜尋現對連線/逾時類錯誤做 2 次指數退避重試（1s、2s），並把總逾時從 12s 提到 20s；「測試搜尋」與實際搜尋共用同一重試邏輯，瞬態抖動不再直接失敗。
- **Bot 裝置查詢 token 安全**：token 改走 Authorization 標頭，不再暴露在 URL 查詢字串。
- **常駐網站圖示**：灰底縮寫升級為真實 favicon（惰性載入）+ 字母兜底。
- **常駐網站聚合**：移除全域 Top 10 URL 截斷，恢復真實網站總數；同一域名跨瀏覽器正確合併來源。
- **時間線/概覽非同步競態**：日期切換、載入更多和模式切換均加序號校驗，舊請求的遲到結果不再覆蓋當前頁面。
- **助手中文輸入法**：IME 組合輸入期間按 Enter 不再誤發送。
- **助手頁狀態**：切頁面不再誤標「已結束」，切回可見生成中氣泡。
- **技術錯誤友善提示**：JS 異常歸攏為「載入失敗，請稍後重試」（四語言），不再把堆疊推到使用者面前。
- **日報頁修復**：西時區日期顯示早一天、快取訂閱未退訂洩漏、TTL 從未生效等。
- **助手頁 XSS 防護**：補齊 DOMPurify sanitize 並升至 3.4.12，修復上游已披露的 sanitize 繞過。
- **監聽器/渲染循環洩漏**：修復 Timeline/Overview 等多處在 await 期間銷毀導致的監聽器與 rAF+WebGL 永久洩漏。
- **即時時間線崩潰**：修復截圖路徑為空時拋錯致使即時更新靜默失效。
- **刪除自訂分類**：歷史活動同步歸類到回退分類，不再在時間線/日報中殘留死 key。
- **資料清理誤刪昨天**：修復「保留今天和昨天」實際刪掉了昨天記錄。
- **IM 機器人**：飛書/釘釘非 2xx 不再誤報成功、飛書 token 按 app_id 區分、裝置名拼錯不再靜默回退本機執行。
- **WebDAV**：目錄 MKCOL 快取（不再逐級重發）、Content-Type 改按副檔名推導。
- **窄窗折疊**：<700px 側欄收為圖示 rail，<640px 時間線讓出完整寬度。
- **桌寵通知邊緣翻轉**（#137）：桌寮靠近螢幕右側時，通知氣泡自動改為向左展開，不再因貼右下角而被視窗裁剪。
- **桌寵穿透按鈕可點擊**（#137）：Windows 此前停用了智慧穿透輪詢，導致開啟穿透後通知卡片按鈕完全點不到；現所有平台統一啟用輪詢（已有快取去抖，無高頻閃爍），滑鼠進入視窗矩形（含按鈕區）時暫時關閉穿透，按鈕恢復正常點擊。
- **彈窗焦點陷阱與無障礙**：Tab 循環聚焦、Toast 補 aria-live、全域動畫降級、hover-only 操作補鍵盤可達。
- **深色模式與 RTL 補齊**：日報、時間線、週期摘要等深色規則與阿拉伯文邏輯屬性適配。
- **CI 門禁**：新增 push/PR 觸發的測試 + 建置門禁與每週安全稽核。
- **日誌隱私**：URL 採集不再寫真實位址到日誌，Bot Token 在錯誤訊息中去識別化。
- **關於頁版本狀態**：設定讀取異常不再把真實版本覆蓋成硬編碼 `1.0.0`，空版本顯示 `--`。
- **開發伺服器邊界**：Vite 限制 CORS 僅接受 localhost，阻止惡意網頁跨源讀取本機開發資源。
- **其他**：標準工時輸入 clamp 到 1~24、概覽時鐘節流、DuckDuckGo 選項標註「免費搜尋（Bing）」等 UI 細節。

## 優化

- **概覽頁改版**：從「資料陳列」到「答案呈現」，KPI 四卡帶參照系（較上週同日 ±），新增洞察條與「今日節奏」主視覺卡。
- **常駐網站以域名為主角**：與應用使用統一為雙層資訊排行、時長軌道和總數頁尾，「查看全部」在原卡片內展開。
- **時間線工作台重排**：活動流改為重點卡片 + 緊湊條目軌道，首屏與即時截圖預熱，詳情依閱讀順序組織。
- **助手原生聊天畫布**：統一頁頭與對話操作，歡迎態複用品牌圖示，快捷問題置中，回答脫離整卡直接排版。
- **日報頁升級**：TL;DR 洞察條、參照系 KPI、匯出下拉選單 + 複製全文、生成設定抽屜、寬屏段落黏性目錄、生成中骨架屏、昨日日報醒目橫幅。
- **日報提示詞預設重構**：從下拉框升級為可見的 chip 集合，點擊套用、懸停編輯/刪除。
- **行式設定系統**：所有設定分頁升級為行佈局，AI 卅 checkbox 換成統一滑動開關，隱私頁收斂為應用規則與內容過濾兩組。
- **設定頁響應式**：中等視窗改用可橫向捲動的分類導航，憑證網格在小屏自動降為單欄。
- **關於頁重排**：品牌主體、版本狀態、產品原則改為置中低雜訊的資訊結構，改用留白分組。
- **服務商選擇器與連接卡**：從裸下拉框升級為 11 家品牌卡片網格（品牌色首字母頭像 + 「使用中」標記）。
- **AI 模型頁三入口分區**：重組為「模型設定 / 助手聯網 / 語意記憶」三個可點擊切換的分區。
- **歷史對話側滑抽屜**：從小彈層升級為頁內右側抽屜面板，帶「新對話」入口。
- **字級階梯規範**：根字級回歸 16px，日期選擇器、助手 meta 等不再低於 10px。
- **統計卡與段落錨點**：統計卡頂部 accent 條 + 數值放大，正文 h2 前置漸層豎條，長報告掃讀有停靠點。
- **三風格側欄指示條**：救活三套風格設計過卻從未渲染的「當前頁指示條」，支援 RTL。
- **撤銷獨立「記憶」頁**：查詢統一走助手，索引管理收進 設定 → AI 模型 → 語意記憶。
- **撤銷「OS 金鑰保險庫」**：刪除 keyring 依賴，設定回歸明文本地儲存。
- **README 三語言與截圖更新**：Bot 聯動擴展到 Telegram/飛書/釘釘/企業微信；刷新各介面截圖與工作流程動圖。
