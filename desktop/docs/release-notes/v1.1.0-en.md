# Work Review v1.1.0

**Release date**: 2026-07-31

A cross-version release (MINOR): new features, no breaking changes.

## New

- **Built-in categorization knowledge base**: Deterministic classification for ~140 website domains + 70 apps. Browser activity is now broken down by site content (Bilibili → Entertainment, GitHub → Development) instead of a blanket "Browser".
- **AI entity auto-learning**: The background auto-classifies unrecognized apps/domains and backfills the last 14 days of history, so categories get more accurate with use.
- **Semantic memory**: A new "Memory" capability that semantically searches screen content you've viewed; supports local Ollama or OpenAI-compatible embedding sources, with automatic fallback to keyword search when embeddings are unavailable.
- **6 new AI providers**: OpenRouter, Groq, xAI Grok, Mistral, LM Studio, and custom OpenAI-compatible endpoints.
- **Model / search test buttons**: "Test model" in the semantic-memory section and "Test search" in the assistant web-access section — verify before enabling.
- **Agent capability expansion**: Loop relaxed to 120s, a stop button, real-time foreground context injection; tools grew from 6 to 12, plus 6 write-action tools that require frontend confirmation (create todo, change category, pause/resume recording, etc.).
- **Conversation persistence**: Assistant history now stored in SQLite (replacing localStorage), with switching / deletion / new-conversation support; old history is auto-imported.
- **Timeline dual drawers**: Hourly summary and activity details moved to right-side drawers, concentrating screenshots, activity info, and category editing.
- **Full-site browsing & semantic editing**: Overview can expand all sites and single-domain details; you can edit a site's semantic category and backfill history.
- **Prompt-injection guard**: External content is wrapped in boundaries to prevent prompt injection; the Gemini key is now sent via header, and system instructions are no longer merged into user content.
- **Hide avatar body** (#137): A new "Hide avatar body" toggle that keeps only notification and reminder bubbles, hides the pet body, and shrinks the window — for users who want notifications without the pet figure.

## Fixed

- **Stats boundary & timezone**: Overlapping work sessions are union-timed, overtime excludes entertainment; cross-midnight sessions are split per day; non-integer timezones (UTC+5:30, etc.) no longer misassign the hourly chart.
- **Unified stats caliber**: Category bar, entertainment ratio, and insight sentences now share the same source as total investment; top-of-page numbers no longer disagree.
- **Privacy filter hardened**: Window titles now filter email/phone/card numbers before storage; fixed a bank-card regex that never worked, leaking card numbers as-is.
- **Duration calculation**: Switching to an ignored app no longer swallows the previous app's last segment; switching back no longer merges into pseudo-continuous intervals.
- **Periodic storage cleanup**: Retention/capacity cleanup now runs every 6 hours in the background, so long-running installs are covered.
- **Telegram Bot reconnect**: Exponential backoff with infinite retries, instead of permanently stopping after 3 consecutive failures.
- **MCP report delegation timeout**: Relaxed from 2s to 120s; uncached AI reports no longer fail delegation.
- **Hourly summary performance**: Only recomputes missing/stale summaries instead of recomputing all 24 hours and writing to DB on every view.
- **Screenshot upload backfill**: Background scan every 10 minutes auto-uploads screenshots missed in the last 72 hours.
- **"Test connection" tests current form values**: What you see is what you test; filling the form and clicking test no longer falsely reports "not configured". Now also covers "Test search" and "Test model" — selecting the free search provider without saving no longer asks for a Tavily API key.
- **Free search (Bing) resilience**: Since `www.bing.com` intermittently times out on some networks (especially in China), free search now retries connect/timeout errors twice with exponential backoff (1s, 2s) and raises the total timeout from 12s to 20s; "Test search" and actual search share the same retry logic, so transient jitter no longer fails outright.
- **Bot device-query token security**: Token moved to the Authorization header, no longer exposed in the URL query string.
- **Persistent site icons**: Gray abbreviations upgraded to real favicons (lazy-loaded) with a letter fallback.
- **Persistent site aggregation**: Removed the global Top-10 URL truncation, restoring real site totals; the same domain is now correctly merged across browsers.
- **Timeline/overview async races**: Date switching, load-more, and mode switching are all sequence-guarded; late results from stale requests no longer overwrite the current page.
- **Assistant IME (Chinese input)**: Pressing Enter during IME composition no longer sends prematurely.
- **Assistant page state**: Switching pages no longer falsely marks "ended"; switching back shows the in-progress bubble.
- **Friendly technical errors**: JS exceptions collapse to "Load failed, please retry" (four languages), instead of dumping a stack trace on the user.
- **Daily-report page fixes**: Western-timezone dates showing one day early, cache subscription leaks, and a TTL that never took effect.
- **Assistant page XSS**: Added DOMPurify sanitize (upgraded to 3.4.12), fixing disclosed sanitize bypasses.
- **Listener/render-loop leaks**: Fixed permanent listener and rAF+WebGL leaks in Timeline/Overview when destroyed during `await`.
- **Live timeline crash**: Fixed an empty screenshot path throwing and silently disabling live updates.
- **Custom-category deletion**: Historical activities are reclassified to the fallback category; no more dead keys lingering in timeline/report.
- **Data cleanup deleting yesterday**: Fixed "keep today and yesterday" actually deleting yesterday's records.
- **IM bots**: Feishu/DingTalk no longer report success on non-2xx; Feishu token now keyed by app_id; misspelled device names no longer silently fall back to local execution.
- **WebDAV**: MKCOL directory caching (no longer re-sent per screenshot); Content-Type now derived by extension.
- **Narrow-window folding**: <700px collapses the sidebar to an icon rail; <640px gives the timeline full width.
- **Avatar notification edge-flip** (#137): When the avatar is near the right edge of the screen, the notification bubble auto-flips to expand leftward, so it's no longer clipped at the bottom-right corner.
- **Avatar click-through buttons clickable** (#137): Windows previously disabled smart click-through polling, making notification-card buttons completely unclickable in click-through mode; polling is now enabled on all platforms (with existing cache debounce, no flicker), so the cursor entering the window rect (including the button area) temporarily disables pass-through and restores button clicks.
- **Dialog focus trap & a11y**: Tab cycling, Toast aria-live, global animation degradation, keyboard reachability for hover-only actions.
- **Dark mode & RTL coverage**: Daily report, timeline, period-summary dark-mode rules and Arabic logical properties.
- **CI gating**: New push/PR-triggered test + build gates and a weekly security audit.
- **Log privacy**: URL collection no longer writes real addresses to logs; Bot tokens are masked in error messages.
- **About-page version state**: A settings-read error no longer overwrites the real version with a hardcoded `1.0.0`; an empty version shows `--`.
- **Dev-server boundary**: Vite restricts CORS to localhost only, blocking malicious pages from cross-origin reading of local dev resources.
- **Other**: Standard work-hours input clamped to 1–24, overview clock throttling, DuckDuckGo option labeled "free search (Bing)", and other UI details.

## Improved

- **Overview redesign**: From "data display" to "answer presentation" — four KPI cards with reference points (± vs. same day last week), a new insight bar and a "Today's rhythm" hero card.
- **Persistent sites, domain-first**: Unified with app-usage into a dual-layer ranking with duration tracks and total footers; "View all" expands within the card.
- **Timeline workbench rearrange**: Activity stream into a highlight-card + compact-rail layout; first-screen and live screenshot warmup; details ordered by reading flow.
- **Assistant native chat canvas**: Unified header and conversation actions, brand icon in welcome state, centered quick questions, answers flowing free of the card.
- **Daily-report page upgrade**: TL;DR insight bar, reference-point KPIs, export dropdown + copy-all, generation-settings drawer, wide-screen sticky section TOC, generation skeleton, and a prominent "yesterday's report" banner.
- **Report prompt-preset refactor**: From a dropdown to a visible chip set — click to apply, hover to edit/delete.
- **Row-based settings system**: All settings tabs upgraded to row layout; AI checkboxes became unified sliders; the privacy page consolidated into app-rules and content-filter groups.
- **Settings responsiveness**: Medium windows get a horizontally-scrollable category nav; credential grids collapse to single-column on small screens.
- **About-page rearrange**: Brand, version status, and product principles in a centered, low-noise info structure grouped by whitespace.
- **Provider selector & connection card**: From a bare dropdown to an 11-brand card grid (brand-color initials + "in use" badge).
- **AI-model page three-section split**: Reorganized into clickable "Model config / Assistant web / Semantic memory" sections.
- **History side drawer**: Upgraded from a small popover to an in-page right-side drawer panel with a "New conversation" entry.
- **Type-scale normalization**: Root font size back to 16px; date pickers and assistant meta no longer drop below 10px.
- **Stat cards & section anchors**: Stat cards get a top accent bar + enlarged numbers; body h2 gets a gradient bar; long reports have rest points for scanning.
- **Three-style sidebar indicator**: Revived the "current-page indicator" designed for all three styles but never rendered, with RTL support.
- **Removed standalone "Memory" page**: Queries now go through the assistant; index management moved to Settings → AI Model → Semantic Memory.
- **Removed "OS key vault"**: Dropped the keyring dependency; config returns to plaintext local storage.
- **README three-language & screenshot refresh**: Bot integrations expanded to Telegram/Feishu/DingTalk/WeCom; refreshed all UI screenshots and workflow animations.
