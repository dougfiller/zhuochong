# Work Review v1.0.55

**Release date**: 2026-07-09

## Fixes

- **Native WebView context menu** (#126): The app shell now globally suppresses the default WebView right-click menu and includes a regression test for listener setup and cleanup.
- **Overview custom date picker** (#119 / #127): The date picker popover is mounted to `body` and positioned with `fixed`, preventing it from being clipped by the overview container; date-range stepping now uses the same range semantics.
- **Assistant time context** (#122): The assistant prompt now receives the current date and time, preventing stale or incorrect time references.
- **Desktop pet multi-monitor position** (#120): Avatar window placement is persisted with monitor-aware positioning to reduce drift after restart or dragging across displays.
- **Settings update toggle**: The auto-update toggle is persisted immediately, avoiding startup behavior falling back to stale config.
- **Startup and Linux release path**: Fixed autostart behavior plus Linux release workflow / packaging validation issues.
- **Build CSS warning**: Prevented Tailwind from treating the Markdown table separator regex as an arbitrary-property class, removing the production CSS minify syntax warning; added a build-warning guard test.

## Improvements

- **Report page**: Refreshed the report layout and tightened Markdown table rendering so tables no longer leave a large blank area on the right.
- **Assistant UI**: Polished model selector sizing, Markdown rendering, and streaming render throttling for smoother long answers.
- **Settings local API**: Local API auto-tests are skipped when the endpoint is disabled or clearly local-only, reducing false alarms.

## macOS install note

On first launch you may see a "damaged" warning. Run:

```bash
sudo xattr -rd com.apple.quarantine '/Applications/Work Review.app'
```
