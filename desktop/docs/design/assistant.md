## 二、问题清单

1. **引用被双重折叠,答案数字无参照系(违反原则①③)** — 消息级引用默认收起在 `<details>`(L926),步骤内引用又藏一层(L903);引用卡不可点击、不能跳到时间线/报告对应位置(L933–949 无任何跳转);「你说我开了 1 小时会」无法一键验证。
2. **会话缺数据上下文提示(联动引用弱)** — 回答基于 `get_today_stats` 等工具,但界面从不展示「AI 正在参考哪个范围的数据」;动态 starter 已经用了今日统计(L766–776),会话中却无此锚点;范围(今天/本周)不可切换,全靠自然语言碰运气。
3. **历史会话动线弱** — 入口是 composer 底部 11px slate-400 文字按钮(L1043–1050),无历史时 disabled,首访不可发现;抽屉列表仅「标题+N 条消息」(L1125–1126),无时间戳、无最后一句预览、无今天/更早分组;标题=首问前 24 字硬截断(L511),无重命名。
4. **删除会话零确认、图标语义错** — `deleteConversation` 直接 invoke(L495–505);触发按钮 hover 才出现且用 X 图标(L1134,惯例=关闭而非删除);删除当前会话时静默清空正文(L498–500)。危险操作未隔离。
5. **双加载指示冗余** — 流式占位消息(「思考中」,L920)与 sending 三点气泡(L962–972)同屏,像两条回复在生成。
6. **步骤条喧宾夺主(违反原则③)** — 多工具时答案上方堆 4–5 行灰底折叠件(L845–916),完成后仍全部保留;读者第一眼看到过程而非答案。
7. **模型选择器与体系脱节(违反原则⑤)** — 原生 `<select>` 样式不可控,靠隐藏 span 测宽 hack(L146–152);「基础模板」与模型档案的差异(是否调用 AI)无任何解释文案(L1019–1022)。
8. **停止操作远离视觉焦点** — 「停止生成」在 composer 左下角(L1025–1033),用户视线在上方流式气泡;失败消息无「重试」,只能重新打字(L710–715)。
9. **空状态未利用数据(违反原则①)** — 欢迎屏只有标题+starter(L817–833),不展示今天已记录多少、能问什么范围;动态 starter 每次进页+每次切模型都发起一次 LLM 请求(L213、L413),慢且费。
10. **视觉 token 漂移(违反原则⑤)** — 页面主色用 indigo/violet(用户气泡 L841、发送键 L1055、rail 高亮),体系主色是 #3b82f6;圆角 28px(L825、L997)偏离 22px 卡基准。

## 三、改版方案

### 信息层级(会话中态)

```
页头:助手 · 会话标题(可改) | 上下文范围 chip(今天/本周/自定义) | 历史(带数)· 新对话
└ 消息流
   ├ 用户气泡(右,primary 淡底,22px 圆角)
   └ 助手回答卡(一个故事一张卡)
      ├ 过程摘要行(单行:「已完成 3 步 · 1.8s」,可展开详情;流式=当前步骤)
      ├ 洞察句(首句加粗 = 直接答案,数字带参照)
      ├ 正文 markdown
      └ 数据引用卡组(平铺 ≤3 张,分类色点+时长+日期,点击跳时间线;多余折叠 +N)
└ Composer(模型胶囊 · 范围提示 | 输入 | 发送⇄停止合一)
```

### 关键交互

1. **上下文范围 chip**:页头常驻「参考:今天 · 已记录 7h24m」,点击切今天/本周/自定义,作为 `chat_work_assistant` 的默认 scope 入参;回答中的相对说法(“下午”“上周四”)有了明确基准。
2. **数据引用卡**:步骤内引用(L903–913)与消息级引用(L926–953)合并为一处,答案下方直接平铺;卡=来源类型角标(活动/小时摘要/日报)+分类色点(六色)+标题+时长+日期+跳转箭头,点击带时间参数跳时间线定位。
3. **过程摘要**:流式时单行显示「正在检索:上周四时段明细…(2/3)」,逐步替换;完成后收为「已完成 3 步 · 展开」;待确认动作保留强制展开(沿用 L848 `open` 逻辑)。
4. **历史会话**:入口升级为页头按钮(带会话数徽标);列表按 今天/本周/更早 分组,行=标题+相对时间+末句摘要;删除→垃圾桶图标+二段确认(点击后变「确认删除?」);长按/菜单重命名。
5. **发送⇄停止合一**:发送键流式时原位变停止(方块),删除三点气泡;失败消息尾部内联「重试」按钮重放同一问题。
6. **模型胶囊**:自绘下拉,选项含 provider 名+「本地/云端」徽标;「基础模板」加副文案「不调用 AI,直接汇总数据」。
7. **空状态=今日快照**:顶部一句洞察(复用后端 get_insights)+「已记录 7h24m · 128 条活动」,starter 卡标注预期答案类型;动态 starter 按 天×模型 缓存,不再每次进页重新生成。
