### P1：矩阵与 JSON 之间的语义一致性未被校验

- 证据：`verify_work_review_regression_baseline.py:153-175` 只验证 JSON 的状态与证据是否非空，并只检查 Markdown 每一行是否存在字段名；它没有比较同一 ID 的 `before_status`、`after_status`、`before_evidence`、`release_blocker`、`known_issue` 等字段值。
