## 1. 改动目标

- 只在用户点击并完成可取消的 3 秒倒计时后，调用唯一无输入的 M1 微信生成 command。
- 将成功收尾固定在私有后端所有权内：`ReplyReady → publish → avatar event → finish`。
- 提供可信设置状态、受确认的留存删除入口和四语白名单错误反馈；不暴露回复、OCR、路径或技术异常。

## 2. 改动范围

- Rust：微信 command/status DTO、私有 reply flow 收尾和 Tauri command 注册。
- 前端：现有桌宠 popover 的显式入口/倒计时/取消/错误展示，微信和知识设置提示，四语 i18n。
- 检测：新增纯静态 `verify_wechat_explicit_trigger.py`，以及错误映射和倒计时 Node 测试。

不新增窗口、配置字段、监听、轮询、快捷键、自动聚焦、输入、粘贴、发送、RAG、Agent/MCP/Bot、上传或 Rust clipboard API。

## 3. 行为变化

```text
用户点击 → 本地 3 秒倒计时（可取消，零后端生成调用）
→ 无输入 generate_wechat_reply command
→ 后端前台复核 / 临时 capture / OCR / 单轮 M1
→ publish 当前建议 → avatar 气泡 → finish lease
```

未知后端异常统一显示通用失败文案；仅固定 `WX_*`/`LLM_FAILED` token 可映射到本地化操作提示。建议仍由既有桌宠协议复制、粘贴和发送，应用不执行这些操作。
