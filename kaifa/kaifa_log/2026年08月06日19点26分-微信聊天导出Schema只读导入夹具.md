## 1. 改动目标

- 冻结唯一支持的 `wechat_archive_v1` JSON 路由，未知版本、字段或结构直接返回 `KB_SOURCE_UNSUPPORTED`。
- 只读消费 manifest 明示的 JSON / integrity 成员；源目录不创建 SQLite、日志、锁或临时文件。
- 将匿名 member metadata、完整性 verdict 与五元组快速核验记录到产品 `data_dir/wechat_knowledge/knowledge.sqlite`。
- 提供覆盖消息类别的完全虚构 fixture，不携带真实账户、会话、消息、正文、附件路径或媒体。

## 2. 改动范围

### 2.1 涉及范围

- 新增 `knowledge/archive_schema.rs`、`archive_importer.rs`、`archive_store.rs`。
- 最小接线 `knowledge/mod.rs`、`knowledge/runtime.rs`，不新增 Tauri command。
- 新增 `tests/fixtures/wechat_archive_v1/` 手写脱敏 fixture。
- 新增 `kaifa/kaifa_test/verify_wechat_json_archive.py`，并补录测试与命令说明。

### 2.2 不涉及范围

- 不读取微信客户端协议、数据库、内存、媒体或未声明目录。
- 不改采集、OCR、模型 transport、前端、发送、桌宠或 Work Review 主库。
- 不添加网络、上传、MCP、Bot、UI Automation、键鼠或自动发送能力。

## 3. 详细改动与行为

| 路径 | 类型 | 作用 |
| --- | --- | --- |
| `desktop/src-tauri/src/knowledge/archive_schema.rs` | 新增 | 严格 v1 probes、字段白名单、coverage 归一化。 |
| `desktop/src-tauri/src/knowledge/archive_importer.rs` | 新增 | allow-list read guard、前后 metadata 审计、逐条 messages visitor、快速核验入口。 |
| `desktop/src-tauri/src/knowledge/archive_store.rs` | 新增 | 仅 dataDir 的 SQLite import/member/event 表与事务记录。 |
| `desktop/src-tauri/tests/fixtures/wechat_archive_v1/` | 新增 | 使用 `acct_fixture_01` 等合成标识的 selected fixture。 |
| `kaifa/kaifa_test/verify_wechat_json_archive.py` | 新增 | 只读静态安全与 fixture 门禁。 |

处理流程：`manifest.json` 严格路由 → 绑定 manifest allow-list → 读取 report / 已声明 integrity / 指定会话 JSON metadata → 顺序 visitor 消费消息 → 比较前后 member metadata → 事务写入 dataDir 派生审计。五元组与 member 审计完全一致时只写 `fast_verified` 事件，不重开 messages 流。

## 4. 输入、输出与接口

- 输入仅为用户已选择的导出目录及其 manifest 明示成员；绝对路径、`..`、符号链接、未声明成员及媒体请求均 fail-closed。
- 内部受限门面为 `KnowledgeStore::import_wechat_json_archive(...)`；未导出为 Tauri DTO 或公开 command。
- 外部错误仍为既有 `KB_SOURCE_UNSUPPORTED` / `KB_NOT_READY`，不包含源路径、正文、真实 ID 或 hash 全值。

## 6. 当前边界与风险

- 大型受控性能样本（约 151 MiB / 108,447 消息）尚未在当前工作区实测；微型 fixture 只证明 visitor 不把整个 messages 数组反序列化为 `Vec<MessageV1>`。
- 真实导出 schema 变化会被严格拒绝，不会做兼容猜测。
- 本阶段不把导入内容接入检索索引或 M2 运行时调用链；既有 M2 retrieval fail-closed 契约保持不变。
