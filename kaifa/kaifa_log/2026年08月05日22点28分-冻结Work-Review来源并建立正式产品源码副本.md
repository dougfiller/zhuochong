## 8. 关键设计决策

### 8.1 以上游 tag 解析提交，而非父仓库 SHA

参考目录无独立 Git 元数据；因此只记录官方 `v1.1.0` 的解析提交，不把产品父仓库的提交伪装成 Work Review 来源。

### 8.2 临时目录验证后原子形成正式副本

`create` 拒绝覆盖既有 `desktop/`。复制、写入 metadata 和全部校验都在同级临时目录完成，失败时仅清理该临时目录，避免半成品被后续步骤使用。

### 8.3 manifest 与产品 metadata 分离

manifest 只覆盖上游受控文件；`docs/baselines/` 的三份产品元数据明确排除于源快照比对之外，防止把新增说明伪装为上游文件。
